# Brazilian E-Commerce Delivery Delay Prediction (DPD601)

## Project Overview
This project provides an end-to-end data science pipeline to analyze and predict order delivery delays (`is_late`) using the Brazilian E-Commerce Public Dataset by Olist.
The prediction scenario simulates the exact moment an order is approved, strictly avoiding data leakage by excluding post-purchase events.

## Data Source & License
